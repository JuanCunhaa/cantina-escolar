# Consultar fonte oficial sob demanda

1. Delimitar uma pergunta que bloqueia a implementação: versão suportada, assinatura/API, contrato, plano ou configuração. Ler lockfile/decisão existente antes de pesquisar novamente.
2. Priorizar documentação oficial e repositório do mantenedor para Next.js/Firebase/Claude/gateway/biblioteca. Usar páginas específicas; não trazer site inteiro para contexto.
3. Confirmar compatibilidade com versão instalada. Para pagamento, conferir uso de recarga fechada, sandbox, autenticação/webhook e estados antes de escrever adapter.
4. Registrar decisão curta, URL e versão/data de verificação em docs/decisions.md ou doc do adapter. Não copiar longos trechos nem tratar preço/promessa antiga como atual.
5. Retomar implementação imediatamente após resolver a dúvida. Se falta credencial/decisão de produto, registrar pendência e continuar partes independentes; não inventar SDK/API.

Sem instalar Context7/MCP adicional só para esta skill: busca direcionada/CLI costuma bastar. Usar servidor de docs já disponível somente se ajudar na dúvida concreta.
