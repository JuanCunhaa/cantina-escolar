# Selecionar contexto

1. Identificar domínio(s) da tarefa em $ARGUMENTS. Ler PROGRESS.md se ainda não estiver carregado.
2. Consultar a(s) entrada(s) correspondente(s) em docs/context-map.json; se houver Fxx, ler apenas docs/tasks/Fxx.md.
3. Ler documentos canônicos pertinentes e os aceites selecionados. Usar docs/spec-index.md somente para lacuna/conflito; não carregar toda a pasta docs.
4. Buscar símbolos/arquivos com rg antes de abrir arquivos grandes. Acrescentar contexto adjacente quando o comando cruza domínios, como checkout + estoque + carteira + políticas.
5. Manter regras globais de CLAUDE.md. Contexto mínimo não autoriza omitir invariantes transacionais.
6. Prosseguir com a solicitação do usuário; não limitar a entrega a um mapa se ele pediu implementação.
