# F10 — Estoque, cotas e custo médio

Etapa: C. Dependências: F06, F07. Estado inicial: pendente.

## Resultado exigido

Implementar entradas físicas/produto acabado, disponibilidade planejada, reservas, lotes/validade opcionais, custo Decimal exato, baixas históricas, inventário/ajustes/perdas e reconciliação. Reserva não é saída. Produção precisa de entrada antes da entrega; custo residual deve ser conservado.

## Skills integradas à execução

Acionar a skill indicada quando chegar à etapa correspondente; não carregar todas de uma vez. Usar a ferramenta Skill do Claude Code quando disponível. A invocação carrega instruções; implementar o resultado e gerar evidência continua sendo responsabilidade do agente.

1. **Use `/cantina-token-economy` para contexto:** Obter metadados desta tarefa pelo script e reduzir buscas/saída sem remover invariantes.
2. **Use `/cantina-architecture` para desenho:** Definir schema/fronteiras/contratos necessários, registrar decisão curta e prosseguir com implementação.
3. **Use `/cantina-testing` para casos de teste:** Planejar/implementar casos dos IDs de aceite relevantes; não rodar a suíte completa nesta etapa.
4. **Use `/cantina-firebase` para persistência e integração:** Implementar documentos, consultas, índices, listeners, Auth, Firestore e/ou transações Firebase afetados; arquivos/fotos pelo módulo de Storage R2 (src/lib/storage), nunca Firebase Storage.
5. **Use `/cantina-finance` para invariantes de negócio:** Preservar atomicidade, idempotência, dinheiro/estoque/uso e validar cenários concorrentes do comando.
6. **Use `/cantina-security` para revisão de acesso e risco:** Revisar os arquivos/comandos alterados, autorização e caminhos negativos; usar scanners quando pertinentes.
7. **Use `/cantina-verify` para validação:** Executar checks já planejados, sem repetição desnecessária, e registrar evidência/pendência por critério.

Condicionais: `cantina-research` só quando faltar informação oficial; `cantina-debug` se houver falha. Não repetir checks já comprovados sem mudança relevante. Se ferramenta Skill não estiver disponível, ler o SKILL.md correspondente e registrar uso por leitura, sem afirmar invocação automática.
